# TaskTomo

AI-assisted task manager. Paste a goal, get a structured plan with subtasks.

## Stack

- **Next.js 14** — app framework
- **Supabase** — Postgres + auth + realtime task sync
- **OpenAI (gpt-4o)** — task decomposition and prioritization

## Setup

```bash
cp .env.example .env.local
npm install
npm run dev
```
